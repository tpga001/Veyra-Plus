## 已有 NR 本机数据

同一隔离管线旧/新 NR 1080p 两轮交替，NR GPU 均值约 **29.40 -> 16.46 ms**。30 FPS 输入、RTX SR 4 档到 4K、DLSS 2x 的离线完整 GPU 跨度：新 1080p 均值约 **29.99 ms / P99 32.22 ms**，新 900p 约 **25.35 ms / P99 27.47 ms**。

这些是特定环境和素材的 GPU 时间，不是实际显示 FPS 或通用性能保证。三组静态同帧证据表明模型与内部尺寸会改变纹理；没有据此证明运动画面完全等价。测试使用默认创建 preset 0，没有将其等同于显式指定 model B 的独立验证。
